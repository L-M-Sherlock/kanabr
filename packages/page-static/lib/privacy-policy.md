# Privacy Policy

kanabr is a Japanese kana typing practice app. The default static app works
without an account or server database.

## Static Local Data

In static mode, your practice history, settings, preferences, and theme are
stored locally in your browser using browser storage such as IndexedDB and
localStorage. This data stays on the device and browser profile where you use
the app unless you export it, import it, reset it, or clear browser site data.

Static mode does not create accounts, public profiles, high scores, multiplayer
sessions, or cloud sync.

## Analytics

The browser app includes Vercel Analytics. Vercel may collect limited usage and
performance information such as page views, device/browser metadata, and request
metadata according to Vercel's analytics service behavior.

## Optional Server Mode

If you run or use a server-backed kanabr installation, the server may store:

* account identifiers such as email address and OAuth profile data,
* public profile name and image,
* typing results, settings, and synchronization data,
* high score and multiplayer data,
* operational logs needed to run and protect the service.

Server mode does not require passwords for kanabr itself when email/OAuth login
is used. Login links should be kept private.

## Optional Third-Party Services

A server operator may enable additional third-party services through
configuration:

* OAuth providers for sign-in,
* email delivery for login links,
* Vercel Analytics for usage analytics,
* Cookiebot and an ad provider when ads are enabled,
* Paddle when paid features are enabled.

If these services are not configured, kanabr does not use them for the
corresponding feature.

## Exporting and Deleting Data

In static mode, use the Profile page to export or reset local data. Clearing
browser site data also removes local kanabr data.

In server mode, signed-in users can delete their account from the Account page.
Deleting an account removes personally identifying account data from that server
installation. If you only want to reset practice statistics, use the Profile
page.

## Changes

This policy may be updated as kanabr changes. Changes are effective when posted
on this page.
